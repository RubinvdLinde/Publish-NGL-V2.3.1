# NGL V2.3.1 — GitHub Pages + Samsung S25

This folder is deployment-ready.

IMPORTANT
Upload the CONTENTS of this folder to the ROOT of the GitHub repository.
`index.html` must sit directly at the repository root.

## First publication
1. Create/sign into a GitHub account.
2. Install GitHub Desktop for Windows.
3. In GitHub Desktop choose File > New repository.
4. Repository name: `ngl`
5. Choose a local folder and create the repository.
6. Copy ALL files/folders from this `NGL_GitHub_Pages` folder into the new repository folder.
7. In GitHub Desktop:
   - Summary: `Publish NGL V2.3.1`
   - Commit to main
   - Publish repository
8. On github.com open the `ngl` repository.
9. Settings > Pages.
10. Source: Deploy from a branch.
11. Branch: `main`
12. Folder: `/(root)`
13. Save.
14. Wait for GitHub Pages to publish.

The URL will normally be:
https://YOUR-GITHUB-USERNAME.github.io/ngl/

## Samsung S25
1. Open the GitHub Pages URL in Chrome.
2. Wait until NGL loads fully.
3. Use NGL's Install button if shown.
   Otherwise: Chrome menu > Add to Home screen > Install app.
4. Confirm Install.
5. NGL should now appear as a standalone app with its own icon.

## Storage
Covers are NOT downloaded as a complete offline collection automatically.
They load from the hosted site as needed.
In NGL Settings you can deliberately download all covers for offline use.

## Future updates
1. Make changes/add games on the laptop.
2. Put changed NGL files in the GitHub repository folder.
3. GitHub Desktop > commit > Push origin.
4. GitHub Pages republishes the update.
5. Open/reopen NGL on the S25 to receive the new version.

Personal phone data such as rankings/notes stays in that browser/PWA storage.
Use Export Backup regularly.
